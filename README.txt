AINA HOPE FOUNDATION — WEBSITE STARTER

Files:
- index.html: website structure and content
- styles.css: responsive styling
- script.js: language toggle, mobile menu, contact form draft

Preview:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Internet connection is needed for Google Fonts and the external photos.

Before publishing:
- Replace YOUR-OFFICIAL-EMAIL@example.org in script.js with the foundation's official email.
- Add official phone number, address, registration details, and social links.
- Replace sample/stock photos with real, consented photos of activities.
- Add verified project updates and impact figures only when available.
- Confirm domain availability and register the chosen domain.
- The contact form currently opens the visitor's email application; it does not store messages on a server.
- No bank details or donation payment processing have been added.

This is a front-end website starter, not yet hosted publicly. It can be deployed to a static hosting provider after the details are finalized.
